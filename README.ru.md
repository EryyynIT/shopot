# shopot

[![CI](https://github.com/EryyynIT/shopot/actions/workflows/ci.yml/badge.svg)](https://github.com/EryyynIT/shopot/actions/workflows/ci.yml)

Визуальный десктоп-клиент для [shopot-core](https://github.com/Puxxalwl/shopot-core/) —
серверлесс P2P-движок обмена сообщениями со сквозным шифрованием и forward secrecy.

Собран на [iced](https://github.com/iced-rs/iced) с программным рендером
tiny-skia на Rust: тёмная палитра в духе TUI, один акцентный цвет, честные
статусы отправки, никаких фейковых квитанций.

![Скриншот](docs/screenshot.png)

## Статус

Первый релиз: **v0.1.0 «Разговор»**. Клиент работает с реальным демоном
`shopot serve` по бинарному кадровому API 1.0.0 через Unix-сокет
(`$HOME/.shopot/api.sock`); `--mock` включает демо-сцену без ядра.

До продакшена ещё далеко: нет истории сообщений, файлов, аватарок и звонков
(v0.2 и v0.3). Дальше — уведомления ОС и полное управление с клавиатуры
(v0.1.1).

Уже сделано:

- типизированный канал ядра: кодек бинарных кадров, корреляция ответов,
  события, реконнект с ресинком; e2e-тест гоняет инвайт → сообщение → ACK
  доставки против двух реальных демонов (гейт по `SHOPOT_BIN`)
- знакомство: одноразовые коды приглашений с QR, добавление по чужому коду
- список контактов с точками presence и бейджами непрочитанных
- лента с разделителями дней, системными событиями и честными статусами
  (отправляю → отправлено / отправится позже / доставлено / не ушло)
- карточка контакта и меню по правой кнопке с блокировкой/разблокировкой;
  Esc закрывает любой диалог
- композер с авторостом и кнопкой отправки
- headless UI-тесты (`iced_test`) и юнит-тесты; CI гоняет fmt, clippy,
  тесты, release-сборку и cargo-deny на каждый пуш

## Скачивание

Релизы — один архив с клиентом, демоном и скриптом запуска для Linux x86_64,
без тулчейнов:

```sh
tar -xzf shopot-v0.1.0-x86_64-linux-gnu.tar.gz
cd shopot && ./run.sh
```

`run.sh` при первом запуске создаёт личность, поднимает демона в фоне и
открывает клиент. Сборка из исходников — ниже.

## Сборка и запуск

Нужны стабильный Rust и [Zig 0.17.0](https://ziglang.org/) для демона.

```sh
# движок: собрать, создать личность, запустить демона
cd core/zig && zig build -Doptimize=ReleaseSafe && cd ../..
./core/zig/zig-out/bin/shopot-zig init
./core/zig/zig-out/bin/shopot-zig serve

# клиент, в другом терминале
cargo run --release
```

Чтобы познакомиться, нажмите «Пригласить» в сайдбаре: диалог покажет ваш
одноразовый код с QR — передайте его вне канала. Чтобы добавить контакт,
вставьте чужой код в «Вставить чужой код» и нажмите «Добавить»; чат откроется,
как только демон узнает обе стороны. Правая кнопка по контакту —
заблокировать/разблокировать; Esc закрывает любой диалог.

## Ядро

shopot — это только клиент; движок — шифрованный P2P-транспорт, сессии,
хранилище — живёт в [shopot-core](https://github.com/Puxxalwl/shopot-core)
от [puxxalwl](https://github.com/puxxalwl). Зафиксированный контракт API —
подмодуль `core` (спецификация бинарного протокола:
`core/zig/docs/CORE-API.md`).
